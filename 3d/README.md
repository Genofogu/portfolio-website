Welcome to the interactive 3D WebGL experience for **Genofogu's** portfolio. This project blends spatial computing, complex React ecosystems, and optimized WebGL rendering.

> [!NOTE]
> Ensure hardware acceleration is enabled in your browser settings for optimal rendering performance.

## 🚀 Key Performance Architectures

1. **Invisible Semantic SEO Fallback:** Strategic `sr-only-seo` indexing DOM injections rendering full semantic trees for search engines.
2. **Asynchronous Shader Compilation:** `gl.compileAsync` during preloading inside `RoomWarmup` boundary.
3. **Adaptive Device Tiering:** Auto-detects memory, cores, and viewport sizes to scale WebGL resolutions and antialiasing on the fly.
